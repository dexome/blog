# Dexome blog site

The production [Astro](https://astro.build) application for
[blog.dexome.com](https://blog.dexome.com), built on the MIT-licensed
[AstroPaper](https://github.com/satnaing/astro-paper) v7.2.0 theme
(see [LICENSE](LICENSE)).

Posts live in `src/content/posts/<slug>/index.md` with their images beside them.

See the [repository README](../README.md) for writing posts, development,
deployment, comments, and analytics.
