# Dexome blog site

The production [Astro](https://astro.build) application for
[blog.dexome.com](https://blog.dexome.com), built on the MIT-licensed
[AstroPaper](https://github.com/satnaing/astro-paper) v7.2.0 theme
(see [LICENSE](LICENSE)).

Posts are written in `../content/en/post/`; `npm run sync:content` generates the
ignored Astro copies under `src/content/dexome/`. Do not add posts in this
directory.

See the [repository README](../README.md) for development, deployment, comments,
and analytics.
